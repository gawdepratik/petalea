# PETALÉA — Minimal Luxury Handmade Website

## Open in VS Code

1. Extract the ZIP file.
2. Open the `PETALEA` folder in VS Code.
3. Open `index.html` in a browser.
4. For the best development experience, install the VS Code "Live Server" extension and use "Open with Live Server".

## Included

- Responsive PETALÉA homepage
- Minimal luxury visual design
- Product cards
- Working front-end cart drawer
- Mobile navigation
- Custom order CTA
- Contact form UI
- Placeholder visual artwork built with CSS
- Empty `images` folder ready for your real product photos

## Important

The cart and contact form are front-end demos for now. Payment processing, order storage, WhatsApp integration, admin panel, and real product images can be connected in the next stage.
